# TraceSummary

One agent invocation — what it ran, how it ended, and when.

## Example Usage

```typescript
import { TraceSummary } from "@albus-ts/sdk/models";

let value: TraceSummary = {
  invocationKey: "<value>",
  sessionId: "<id>",
  status: "RUNNING",
  spansExpired: false,
  startedAt: new Date("2026-03-07T21:24:25.396Z"),
};
```
