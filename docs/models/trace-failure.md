# TraceFailure

Why an invocation failed, and what to show for it.

## Example Usage

```typescript
import { TraceFailure } from "@albus-ts/sdk/models";

let value: TraceFailure = {
  kind: "crash",
  message: "The invocation failed. Try again.",
};
```
